已建普通建筑例外已获用户批准并原生通过：[记录62](../Civ6_GrandCampaign_Research/docs/62-human-completed-building-refund-20261009.md)。正常50回合/自治100后正式恢复两城、首都/宫殿与原勇士8点；保留宗主建成的粮仓和完整原档案，原队列去除已完成项，原5点存入独立返还账本。复国后在该城市自行选择合法生产；待原生溢出和当前生产基线明确，系统按精确整数批次返还，界面显示余额。不选生产不发奖，余额未结清不能再次附庸。粮仓案例实际4.0→9.0精确返还5点；选择前/完成点保存重载、下一回合不重复均通过。区域按位置完整读取，保留宗主新增的卫城及退出队列的未完成奇观脚印。其他生产类型、小数/特殊倍率和多项队列仍需专门验收。

仅在可丢弃的新单人测试局启用真实模式；旧观测存档不能只改开关升级，因为建局时必须加载零城市存活规则。
